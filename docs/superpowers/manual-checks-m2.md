# 里程碑 2 手动验收清单（颍川之战可玩）

启动：`npm run dev` → 浏览器打开提示地址（桌面优先，Chrome/Safari 最新版）。

## 标题与进入
- [ ] 标题画面显示「三国志 · 曹操传」，点击「开始颍川之战」进入战场
- [ ] 进入后自动弹出开场对话（曹操/夏侯惇/荀彧 三行，打字机逐字），点击推进（先补全本行再翻行），末行点击后关闭

## 战场渲染
- [ ] 16×12 地形正确：草地/树林/山丘/水域/营寨（张梁张宝所在）/桥，水面有波纹动画
- [ ] 我方蓝色调、敌方红色调；六个兵种剪影可分辨（君主持剑/步兵盾枪/骑兵马身/弓兵弓弧/军师摇扇/道士执杖）
- [ ] 单位脚下阵营色环、头顶血条（变色阈值 50%/25%）、已行动单位变暗

## 我方回合交互
- [ ] 点选我方单位 → 蓝色移动范围（不含水面/占位格）
- [ ] 点范围格 → 单位滑动过去，弹出横排动作菜单（攻击/法术/道具/待机/撤销）
- [ ] 撤销 → 单位回到原位、菜单关闭、可重选移动格
- [ ] 攻击 → 敌方可击目标红色高亮 → 点击目标：突进/闪白/伤害飘字（先动画后数字）→ 若击杀则淡出
- [ ] 法术 → 菜单列出法术与 MP → 选择后紫色射程圆盘 → 悬停显示 AoE 形状预览 → 点击施放：法阵爆发 + 治疗/伤害数字
- [ ] 道具 → 列出携带道具 → 使用回血/回蓝
- [ ] 非法操作（超射程攻击/MP 不足/天气禁施等）有 toast 且状态不变
- [ ] 待机 → 单位变暗、选中清空

## 敌方回合与回合流
- [ ] 结束回合 → 「敌军行动」横幅 → 敌军逐个移动/攻击/施法有动画 → 「第 N 回合」「我军行动」横幅 → 回到可操作
- [ ] 第 3 回合敌方增援入场并有对应对话触发（士兵报信 + 曹操回令）
- [ ] 击杀张梁触发剧情对话（张梁遗言 + 曹操收尾），对话点完后才弹结算画面

## 镜头与 HUD
- [ ] 鼠标滚轮/方向键平移镜头（边界夹取）；窗口缩放自适应
- [ ] 底部信息面板：选中/悬停单位的名/级/HP/MP/四维/装备/状态
- [ ] 悬浮提示：地形防御加成、敌单位概要、与选中单位的相克倍率
- [ ] 对话展示期间：画布点击/键盘/「结束回合」均被锁；「退出」仍可用

## 结算
- [ ] 全歼敌方 → 胜利画面（回合数 + 重新开始/返回标题），结算层盖过一切浮层（无 tooltip 残留）
- [ ] 曹操阵亡或超回合 → 败北画面
- [ ] 重开 → 新 seed 重启整场（含开场对话重新展示）

## 已知限制（验收时知悉，不算缺陷）
- 施法目标拾取为宽松判定：点击棋盘内任意格子均作为施放点提交（不做严格射程圆盘判定），非法目标由引擎拒绝并以 toast 提示；点击棋盘外区域退回法术菜单而非直接取消
- 敌方回合多批横幅批期间，画面短暂保持回合前基态（动画链式播放的已知取舍，最终状态正确）
- 对话推进仅支持鼠标点击（Enter/空格不推进）——如手感不佳列入 M3 改进
