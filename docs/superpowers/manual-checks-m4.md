# M4 人工验收清单（npm run dev）

> 自动化测试覆盖纯逻辑（引擎/数据/campaign/saves/集成）；以下为 UI 装配层人工验收。
> 每项打勾前须实际操作一遍；发现异常记入「已知限制」。
> 时间轴全序：颍川 → 汜水 → 虎牢（M3 手册已验）→ 青州 → 徐州 → 濮阳 → 宛城 → 下邳；本册只验后五场与终局流程。
> 界面不显示格子坐标；坐标、回合数、回合上限等细节以数据文件为准，按括注地形特征在图上定位。
> 三档结局各条需新档通关 8 战方可验（每档数十分钟），宜留最后验。

## 1. 五场新战役

### 青州讨伐战（全歼敌军）
- [ ] 整备屏显示「本关新参战：于禁（战后入册）」；开场对话（曹操/荀彧论贼）后开局
- [ ] 第 3 回合触发于禁请战对话；第 5 回合地图上缘增援两员黄巾贼
- [ ] 首员黄巾渠帅（骑兵）被击破 → 专属阵亡对话
- [ ] 胜利条件 = 全歼敌军：只杀渠帅不出胜利横幅，清场才结算（回合上限 20）
- [ ] 踏上东城马厩城池格 (13,6) → 浮字「获得宝物」；中南部平地 (9,8) 同理；结算屏「缴获/拾获」列出的卢、还神丹

### 徐州复仇战（击破陶谦）
- [ ] 整备屏显示「本关新参战：许褚（战后入册）」；开场对话（曹操起兵复仇）后开局
- [ ] 第 2 回合触发许褚报名对话；陶谦幕僚会贴身治疗陶谦、丹阳兵守两桥头（体感）
- [ ] 击破陶谦 → 专属阵亡对话 → 胜利（回合上限 16）
- [ ] 本关无宝物格，奖励走战后抉择（见 §2）；无增援

### 濮阳之战（击破吕布）
- [ ] 整备屏显示「本关新参战：郭嘉（战后入册）」；开场对话（曹操/陈宫/吕布叫阵「吾自出城破之」）后开局
- [ ] 郭嘉为我方首个 debuff 施法者：其行动菜单「法术」可选 破甲/眩晕/妖雾（此前我方无人可施 debuff）
- [ ] 第 3 回合触发陈宫献策对话；敌方吕布军妖道会对我方施 debuff（M3 已知限制清偿，体感）
- [ ] 城墙三门（北/中/南缺口）择路攻城；击破城心吕布 → 专属阵亡对话 → 胜利（回合上限 20）
- [ ] 城内城池格 (17,2) 孙子兵法、城内空地 (15,6) 还神丹；结算屏拾获列出

### 宛城之战（撤退点突围）
- [ ] 整备屏无「本关新参战」标记（本关无新武将）；开场对话为夜袭被围（张绣/典韦/曹操）
- [ ] 典韦为固定参战：整备无下场机制，我方 7 人全员上阵（断后剧情以其在场为前提）
- [ ] 第 4 回合触发典韦断后对话；典韦若阵亡 → 专属阵亡对话，且不拦撤退胜利
- [ ] 第 3/5/7 回合各增援两员张绣军枪兵（西缘 → 南缘 → 兜底），拖延渐被合围（体感）
- [ ] 胜利条件 = 曹操抵达西南关隘 (1,11)（第 12 行左端两格关隘的右格）：开到该格立即胜利，无需歼敌；残局下只走曹操一人到关隘格同样立即触发胜利横幅
- [ ] 拖满 14 回合未抵达撤退点 → 判负（败北横幅 + 重新挑战）
- [ ] 撤退路中段平地 (7,8) 金创药、东南角林地 (12,10) 还神丹

### 下邳之战（击破吕布·终战）
- [ ] 整备屏显示「本关新参战：荀攸（战后入册）」；开场对话荀攸首行献水攻之策
- [ ] 我方自西南登陆区推进，南/西水泽环城可涉渡（非唯一通道）
- [ ] 击破城心吕布（Lv10）→ 白门楼专属阵亡对话 → 胜利（回合上限 24）
- [ ] 城内城池格 (14,2) 双铁戟、登陆桥北 (6,9) 金创药；结算屏拾获列出

## 2. 战后抉择三处
- [ ] 徐州胜后结算屏报告下方弹抉择（荀彧发问）：「出安民告示…（仁）」/「纵兵屠城…（暴）」，选项文案直接标注「（得 明光铠）」
- [ ] 宛城胜后弹抉择（曹操发问）：抚恤降卒收编（仁）/ 尽诛张绣旧部（暴），无物品奖励
- [ ] 下邳胜后弹白门楼抉择（刘备发问）：斩之以正军法（仁）/ 招揽吕布为己用（暴）
- [ ] 未作答时结算屏「继续」按钮置灰不可点；任选一项作答后按钮解禁
- [ ] 作答即时落自动档：作答后刷新页面 → 「继续征程」回进度屏、同抉择不再弹出；进度屏「导出 JSON」可见 morality 与 choicesMade 已记录
- [ ] 徐州选屠城 → 明光铠入仓库（回整备屏可装备验证）；选安民则无物品

## 3. 水淹下邳（第 6 回合三重奏）
- [ ] 第 1-5 回合 HUD 天气为「晴」；第 6 回合起转「雨」，此后每回合直至终局均为「雨」
- [ ] 第 6 回合同屏触发水淹对话（曹操决堤 → 陈宫 → 吕布）
- [ ] 同回合城东缘增援两员并州兵 (16,6)/(18,8)
- [ ] 转雨后选荀彧/荀攸施法：法术列表不再出现火系法术（雨天火系门禁，转雨前可见）

## 4. 三档结局
- [ ] 新档三抉择（徐州/宛城/白门楼）皆选仁 → 结局屏「治世之能臣」，忠奸之评显示 +3
- [ ] 新档三抉择皆选暴 → 「乱世之奸雄」，忠奸之评 −3（屠城得明光铠不影响分档）
- [ ] 新档混合作答（净值为 +1 或 −1，如两仁一暴）→ 「非常之人，超世之杰」居中结局

> 分档口径：忠奸 ≥+2 忠臣 / ≤−2 奸雄 / 其余居中（判定依据，非操作项）

- [ ] 终战结算「继续」进结局屏（不回进度屏）；结局屏「返回标题」后「继续征程」读自动档 → 进度屏显示「八章全通 · 乱世已成」，无整备入口

## 5. 存档兼容
- [ ] 导入 M3 时期导出的 JSON（无 morality/choicesMade 字段；无旧文件可在新导出 JSON 中删去这两个字段模拟）→ 正常读取，忠奸为 0、无已答抉择，可继续推进
- [ ] 新档导出 JSON → 清空 localStorage（DevTools）→ 导入恢复：morality/choicesMade 与导出前一致（往返无损）
- [ ] DevTools 手改档位数据 morality 为非整数（如 1.5）→ 该档显示「已损坏」且读取按钮不可点，游戏不崩溃

## 已知限制
- 结局屏无「重看」入口：回标题后自动档已通关（进度屏只显示「八章全通」），需从终战前的档位读档重打下邳方可再见结局
- 结算屏抉择未作答即刷新/关页：该战 ±1 永久流失（自动档已推进且无补弹机制），档位可能因此偏移一档；作答后再离开无此问题
- 音效未做（spec「视情况」项，登记延后）
