# Web 版《三国志曹操传》设计文档

日期：2026-09-08
状态：已与开发者逐节确认

## 1. 概述

用 Web 技术复刻 Koei 1998 年经典战棋 RPG《三国志曹操传》的核心体验：
回合制战棋战斗 + 武将养成 + 剧情驱动的战役进程。视觉为程序化自绘像素风
（致敬风，不复用原版素材，无版权风险）。

### 规模：核心可玩版

完整战棋核心系统 + 武将养成升级装备 + 8 场经典战役串成剧情线（颍川之战 →
下邳之战），一个可通玩的完整体验，架构上支持后续扩展更多战役。

### 已确认决策

| 维度 | 决定 |
|------|------|
| 规模 | 核心可玩版（8 场战役 + 完整战棋核心 + 养成） |
| 技术栈 | Vue 3 + TypeScript + Vite + Canvas 2D |
| 架构 | 数据驱动 + 纯逻辑战斗引擎（事件序列驱动渲染） |
| 美术 | 程序化自绘像素风（零外部素材） |
| 系统 | 忠实核心（兵种相克/地形/天气/法术/反击暴击/装备/宝物/善恶抉择） |
| 平台 | 桌面浏览器优先，鼠标点选操作 |
| 存档 | localStorage 3 手动档 + 1 自动档，支持导出/导入 JSON |

### 非目标（本期不做）

- 转职系统、全宝物图鉴收藏、单挑小游戏（单挑以剧情演出呈现）
- 商店经济系统（装备靠战场缴获与宝物）
- 手机/触屏适配、联机对战
- 音乐与语音（仅 Web Audio 合成简单音效，里程碑 ④ 视情况加入）
- 原版素材复刻（版权风险，明确排除）

## 2. 总体架构

三层分离，依赖单向：引擎（纯逻辑）→ 渲染（Canvas）→ 界面（Vue）。
引擎层不 import 任何 Vue/Canvas 模块，保证规则逻辑可被 Vitest 直接测试。

```
caocaozhuan/
├── src/
│   ├── engine/            # 纯 TS 战斗引擎（零 DOM/Vue 依赖）
│   │   ├── types.ts       # 状态/指令/事件 类型定义
│   │   ├── engine.ts      # apply(state, command) → { state, events }
│   │   ├── combat.ts      # 伤害/反击/暴击/相克公式
│   │   ├── movement.ts    # BFS 移动范围/攻击范围/寻路
│   │   ├── ai.ts          # 敌方/友军 AI（启发式）
│   │   └── wincheck.ts    # 胜负条件判定
│   ├── data/              # 数据驱动内容（纯数据，无逻辑）
│   │   ├── classes.ts     # 兵种定义（6 种 + 相克表 + 成长率）
│   │   ├── heroes.ts      # 武将档案
│   │   ├── items.ts       # 装备/道具/宝物
│   │   ├── strategies.ts  # 法术定义
│   │   └── battles/       # 每场战役一个文件
│   ├── render/            # Canvas 渲染层
│   │   ├── battlefield.ts # 网格/地形/高亮/镜头
│   │   ├── sprites.ts     # 程序化像素绘图
│   │   └── animator.ts    # 事件序列 → 动画播放
│   ├── ui/                # Vue 3 界面层
│   │   ├── screens/       # 标题/进度/整备/战斗/结算
│   │   └── components/    # 对话框/状态面板/法术菜单/装备界面
│   └── game/              # 编排层：界面流转、存档、战役进度
├── tests/                 # 引擎单元测试（Vitest）
└── index.html / vite.config.ts
```

### 数据流（单向循环）

```
玩家点击 → Vue 组件 → 编排层构造 Command（如 AttackCommand）
→ engine.apply(state, command) → { 新状态, 事件序列 }
→ animator 播放事件动画，Vue 状态栏同步刷新
```

### 关键约束

- 引擎层零框架依赖，可独立单测
- 战役全部是数据：新增战役零逻辑代码改动
- 状态不可变（immutable）：每次 apply 产出新状态对象（悔棋与存档快照的基础）

## 3. 战斗引擎规则

### 3.1 属性

每武将 6 项属性 + 等级/经验：HP、MP、攻击、防御、精神（法术攻防）、
敏捷（命中/闪避/连击）。升级按兵种成长率随机成长（原版风味），
等级上限 30（8 场战役的节奏值，数据可调）。

### 3.2 兵种（6 种）

| 兵种 | 定位 | 特点 |
|------|------|------|
| 君主 | 均衡近战 | 曹操专属，可装备大多数宝物 |
| 步兵 | 防御型 | 克骑兵，山地适应好 |
| 骑兵 | 机动型 | 移动力最高，克弓兵 |
| 弓兵 | 远程型 | 射程 2~3，克步兵，被贴脸弱 |
| 军师 | 法术输出 | 火系/水系攻击法术 + 回复 |
| 道士 | 辅助 | 增益/减益/控制类法术 |

相克三角：骑兵 > 弓兵 > 步兵 > 骑兵（相克系数表为数据，平衡随时可调）。
军师/道士/君主中立。典韦/许褚等猛将归步兵系，以成长率侧重（高攻低防）
拉开个性差异。

### 3.3 核心公式（全部纯函数，位于 combat.ts）

```
物理伤害 = max(1, (攻击 − 防御×0.6) × 相克系数 × 地形防御系数 × 浮动(0.9~1.1))
           × 暴击(×2，由敏捷差决定概率) × 连击(×2，敏捷压制时概率触发)
反击：被攻击者存活且攻击者在其射程内 → 反击一次（伤害 ×0.8）
法术伤害 = (法术威力 + 精神×0.8 − 目标精神×0.4) × 天气系数
命中/闪避：基础 90% ± 敏捷差修正
```

### 3.4 地形与移动

地形：平原/森林/山地/水域/城池/营寨/关隘/桥。各有防御加成%（森林 +15、
城池 +30 等）和分兵种移动消耗（骑兵平原 1/山地 4，步兵全地形均衡）。
BFS 计算移动范围（蓝色高亮）与攻击范围（红色高亮）。

### 3.5 天气

晴/阴/雨，按战役脚本或概率变化。雨天火系法术不可用、水系伤害 +50%。

### 3.6 法术（10 个，数据定义）

| 法术 | 类型 | 效果 |
|------|------|------|
| 火矢 | 攻击 | 单体火伤 |
| 火龙 | 攻击 | 十字范围火伤 |
| 水淹 | 攻击 | 范围水伤，雨天 +50% |
| 落石 | 攻击 | 单体，山地地形加成 |
| 治愈 | 回复 | 单体回复 HP |
| 群疗 | 回复 | 范围回复 HP |
| 破甲 | 减益 | 降低防御 |
| 疾风 | 增益 | 提升移动力 |
| 眩晕 | 控制 | 目标跳过下回合行动 |
| 妖雾 | 减益 | 降低命中 |

法术效果以数据 + 效果函数表实现（每种效果一个函数，新增法术零 if-else）。

### 3.7 经验与升级

攻击命中/施法成功获得经验，击杀 ×2。满 100 升级，按兵种成长率随机提升属性。

### 3.8 胜负条件（每战役数据定义）

胜利：歼灭全敌 / 击破指定主将 / 坚守 N 回合 / 曹操抵达撤退点。
失败：曹操阵亡或我方全灭。
回合事件：回合数触发敌军增援、剧情对话、天气变化。
宝物格子：单位抵达指定格子获得宝物（不提示位置，原版探索风味）。

### 3.9 敌方 AI（启发式）

对每个可攻击目标计算期望伤害 ×（可击杀加权 + 威胁度），军师优先施法；
无目标时向最近敌人推进；保护本方主将。友军（可选阵营，部分战役启用）
共用同一 AI。

## 4. 剧情与养成系统

### 4.1 对话系统

战前/回合触发/战后对话脚本：说话人 + 程序化头像 + 文本 + 打字机效果。
关键对话提供善恶抉择（原版精髓），累积忠奸值，通关结局文案分
忠臣/奸雄/中间三档。单挑以剧情演出呈现（特写 + 固定结果脚本）。

### 4.2 装备与宝物

装备三槽位：武器（加攻）/防具（加防）/辅助（移动/HP/MP 等）。
战场缴获：击破特定敌将掉落；宝物格拾取。战前整备界面更换装备。
战斗道具：金创药（回复 HP）/还神丹（回复 MP），战斗中消耗行动使用。

## 5. 界面与渲染

### 5.1 游戏流程

```
标题画面 → 战役进度总览 → [战前剧情 → 战前整备 → 战斗 → 战后结算/剧情] 循环 → 结局
```

| 界面 | 内容 |
|------|------|
| 标题/进度 | 新游戏、继续（读档）、战役时间轴 |
| 战前整备 | 武将列表、状态详情、装备更换、出战确认 |
| 战斗 | Canvas 战场 + 底部状态条 + 右键动作菜单 |
| 结算 | 经验获得、升级明细、宝物拾取、剧情 |

### 5.2 Canvas 渲染

战场最大 64×64 格，格子 32px。视口滚轮/边缘拖拽平移。程序化像素绘图：
地形色块 + 抖动噪声（森林深绿噪点、水域波纹帧动画），单位 16×16 像素小人
（兵种配色）+ 阵营底圈（我方蓝/敌方红/友军绿）。动画器消费引擎事件：
移动逐格滑动、受击闪白、伤害数字上飘、法术色彩特效、死亡淡出。

### 5.3 战斗交互（忠实原版）

点选单位 → 蓝色移动范围 → 点目标格移动 → 动作菜单（攻击/法术/道具/待机）
→ 攻击选红色目标 → 演出结算。支持行动前撤销移动、回合结束按钮、
地形/相克悬浮提示。

## 6. 存档

localStorage 三手动档 + 一自动档（每战役开始时写入）。快照 = 完整游戏状态
JSON（不可变状态的直接收益）。支持导出/导入 JSON 文件备份。

## 7. 错误处理

引擎所有非法指令（移动超范围/攻击友军/MP 不足）返回类型化错误而非抛异常；
Vue 层统一 toast 提示；存档损坏时降级到自动档并警告。

## 8. 测试策略（Vitest）

- combat.ts：相克/暴击/反击/地形边界值用例表（重点区）
- movement.ts：复杂地形寻路、封锁路径
- engine.ts：完整回合模拟（天气变化、增援触发、胜负判定）
- wincheck.ts：每种胜负条件正反用例
- ai.ts：给定局面断言选择合理目标
- 目标：引擎层行覆盖 ≥ 80%（UI 层以手动验收为主）

## 10. 里程碑

1. **引擎**：类型 + 公式 + 移动 + 胜负 + 单测全覆盖
2. **单场可玩**：渲染 + 交互 + AI，颍川之战可完整打完
3. **养成闭环**：升级/装备/道具/存档 + 前 3 场战役 + 整备界面
4. **完整体验**：8 场战役 + 剧情对话 + 善恶抉择 + 三档结局 + 音效（视情况）
